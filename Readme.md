# CoteFoto

Aplicație Android dedicată măsurătorilor și adnotărilor pe imagini. 

## Funcționalități principale
* **Trasare cote:** Permite desenarea liniilor de cotă direct pe fotografii.
* **Adăugare valori:** Posibilitatea de a introduce dimensiuni și valori exacte pe fiecare cotă trasată.
* **Notițe pe imagine:** Adăugarea de observații și detalii suplimentare direct peste fotografie.
* **Export JPG:** Salvarea rapidă a imaginilor finalizate într-un folder dedicat, în format `.jpg`.

## Descărcare și instalare
Poți descărca ultima versiune a aplicației (fișierul `.apk`) din secțiunea **Releases** din dreapta paginii.
